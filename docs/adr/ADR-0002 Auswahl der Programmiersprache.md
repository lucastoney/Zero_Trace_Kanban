# ADR 0002: Python als Programmiersprache

*Status:* Accepted 
*Datum:* 05.11.2025
*Autor:* Sam / Team  
*Betroffene Bereiche:* Coding, Front, Backend

---

##  1. Kontext

### Programmiersprache

Wir brauchen eine Programmiersprache die...
- einige von uns bereits beherrschen
- sich für Front und Backend eignet
- sich für den Lokalbetrieb eignet

Zur Auswahl stehen:
- Phyton
- C#
- C++

## 2. Entscheidung

 **Wir entscheiden uns für:**  
- Python als Programmiersprache für den MVP front und Backend.
