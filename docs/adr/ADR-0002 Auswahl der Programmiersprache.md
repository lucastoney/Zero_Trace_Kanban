# ADR 0002: Auswahl der Programmiersprache

*Status:* Accepted  
*Datum:* 05.11.2025  
*Autor:* Sam / Team   
*Betroffene Bereiche:* Coding, GUI, Scann Engine (Backend)  

---

##  1. Ausgangslage

### Programmiersprache

Wir brauchen eine Programmiersprache die...
- einige von uns bereits kennen und lesen können
- sich für das GUI und die Scann Engine eignet
- sich für den Lokalbetrieb eignet

Zur Auswahl stehen:
- Phyton
- C#
- C++

## 2. Entscheidung

 **Wir entscheiden uns für: Python**  
- Python als Programmiersprache für den MVP im GUI und der Scann Engine.
